# ShopNest Troubleshooting Guide

## App and Website Issues
### App crashes or won't open
1. Ensure you have the latest version of the ShopNest app.
2. Restart your device.
3. Clear app cache (Settings > Apps > ShopNest > Clear Cache).
4. If the issue persists, reinstall the app. Your account data is saved.

### Website not loading or errors at checkout
1. Refresh the page and try a different browser.
2. Disable browser extensions/ad blockers temporarily.
3. Check your internet connection.
4. If payment step fails, verify card details and try an alternate payment method.

## Login and Verification
- **Not receiving OTP/reset email**: check spam/junk, ensure correct email/phone on file, wait 2 minutes and resend. Corporate email filters may block messages.
- **Two-factor issues**: use backup codes if available; otherwise contact support for identity verification.

## Promo Codes and Discounts
- Ensure the code hasn't expired and meets minimum order/cart conditions.
- Only one promo code can be applied per order unless stated.
- If a valid code fails, share the code and a screenshot/error message with support.

## Subscription Issues
- To change plan or payment method: Account > Subscriptions > Manage.
- If billed after cancellation, confirm cancellation date/time and contact support with invoice details for review.

## When to Escalate
Escalate to a specialist/supervisor when: repeated technical failures after troubleshooting, suspected fraud/unauthorized access, refund delays beyond policy timelines, or customer explicitly requests a supervisor.
